# AI Context Guide

This file is written for AI coding agents and future maintainers. Read it before modifying the project.

## Project Identity

This is a BSC Quant/Strategic Research static report generator. The output is a polished financial report, not a generic website. Preserve institutional formatting, Vietnamese text quality, table readability, chart readability, and PDF/share export quality.

## Current Active Branch

Use branch `LL` for active development. It was created from cleaned `main`.

Known branch roles:

- `main`: clean baseline branch without the accidental nested upload folder.
- `LL`: active development branch.
- `gianganh-intheflow-patch-1`: flattened branch containing a larger Python/module pipeline prototype.

Do not assume files from `gianganh-intheflow-patch-1` exist on `LL` unless they have been merged.

## Current Architecture On LL

The current architecture is PowerShell-based:

```text
build.ps1 -> dist/*.html
export.ps1 -> dist/*.pdf and dist/*.png
```

Source directories:

```text
data/
theme.config.json
src/partials/
src/templates/
assets/
references/
```

Generated directory:

```text
dist/
```

Treat `dist/` as generated. Durable fixes should generally happen in `data`, `theme.config.json`, `src`, `build.ps1`, or `export.ps1`.

## Critical Visual Requirement

The visual reference is:

```text
references/BSC_Quant_Research_editable_saved.html
```

When the user says to keep format, preserve:

- table structure and column proportions
- chart styling and line colors
- Nunito font usage
- BSC blue/teal color treatment
- text colors
- stock card treatment
- PDF page fit
- share-card ratio and visual treatment

Only adjust spacing and size through global setup where possible.

## Build And Verification Commands

Primary commands:

```powershell
npm run build
npm run export
```

Direct equivalents:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
powershell -ExecutionPolicy Bypass -File export.ps1
```

Post-build checks:

```powershell
rg "##[A-Z_]+##|\{\{[^}]+\}\}" dist
rg "QR Offline" dist/share.html dist/BSC-QUANT-2026-07/share.html
```

`export.ps1` may require normal local execution because Edge headless can be blocked by a sandbox.

## Editing Rules For AI

Prefer this order:

1. Read current branch and `git status`.
2. Read relevant source files before editing.
3. Edit source, not generated output, unless explicitly asked.
4. Build after source changes.
5. Export when PDF/share output matters.
6. Report what changed and what was verified.

Avoid:

- deleting user changes
- using destructive Git commands unless explicitly approved
- editing `dist` as the only fix
- changing the report visual language casually
- replacing Vietnamese text without checking encoding carefully
- mixing the Python prototype branch into `LL` without an explicit decision

## Important Implementation Details

`build.ps1` validates:

- `meta.docCode` format
- type scale minimum `12px`
- share top picks are valid tickers
- total recommendation weight equals `100`

`export.ps1` validates:

- PDF file exists
- PDF page count does not exceed `data.meta.pageCount`
- share screenshot is generated by Edge

`theme.config.json` controls global colors/type/spacing. If a user asks to change only spacing or size globally, start there.
